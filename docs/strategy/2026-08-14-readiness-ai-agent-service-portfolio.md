# 준비도 진단 기반 AI 전문가 서비스 포트폴리오

> 작성일: 2026-08-14
> 상태: 조사·상품 설계 초안
> 적용 대상: Global GTM Platform 준비도 진단 55문항
> 가격 상태: **모든 가격은 검증 전 상품 가설**이며 실제 결제 전 고객 인터뷰·전환 실험으로 검증해야 한다.

## 1. 결론

현재 준비도 진단은 55개 문항을 12개 항목으로 묶고 낮은 응답을 액션과 사람 전문가 서비스로 연결한다. 이를 AI 서비스로 전환할 때 문항마다 별도 챗봇을 만들기보다, 창업기업이 직접 수행하기 어려운 **외부조사·비교·계산·문서화·상세계획 수립**을 결과물 단위로 묶는 편이 적합하다.

권장 구조는 다음과 같다.

- 7개 전문 에이전트가 시장정보, 고객검증, 현지화, 규제, 현지 네트워크, 재무, 실행계획을 각각 담당한다.
- 1개 총괄 오케스트레이터가 진단 답변을 라우팅하고 Critical·Gate 순서로 작업을 배치하며 결과를 하나의 실행보고서로 통합한다.
- AI가 공개자료 조사와 초안 작성을 완료하되, 법률·세무·인허가·계약 효력과 실제 현지 관계는 `사람 검증 필요`로 분리한다.
- 단건 에이전트와 목적별 묶음 상품을 함께 제공한다. 오케스트레이터는 별도 판매하지 않고 모든 상품에 포함한다.

## 2. 근거, 추론, 상품 가설

### 직접 확인한 근거

- `lib/intake-questions.ts`에는 준비 3단계, 12개 진단 항목, 55개 질문, 질문별 액션·Critical 여부·기존 `serviceTag`가 정의되어 있다.
- `lib/service-data.ts`의 기존 사람 서비스 가격은 120,000원~2,800,000원이며 멘토링과 수주형 컨설팅이 섞여 있다.
- `lib/expert-matching.ts`는 규제 업무와 현지 실증·첫 주문·파트너 확보를 사람 전문가 추천 대상으로 분류한다.
- Obsidian 볼트는 시장선정, BMLC, LPA, TCE, 현지 네트워크, 30·60·90일 계획의 입력과 산출물을 정의하고 있다.
- 볼트의 AI 운영 가드레일은 조사·요약·초안·분류는 자동화할 수 있지만, 고위험 규제·금전·계약 판단과 새로운 시장의 첫 현장학습은 사람 확인 대상으로 둔다.
- OpenAI 공식 모델 문서에서 GPT-5.6 Sol의 2026-08-14 기준 API 단가는 100만 토큰당 입력 US$5, 캐시 입력 US$0.50, 출력 US$30이다. 검색 등 도구 호출료는 별도다.

### 분석적 추론

- 12개 진단 항목을 그대로 상품화하면 동일한 시장·기업 정보가 여러 서비스에서 반복 조사되어 비용과 사용자 피로가 커진다.
- 문항별 동적 에이전트는 개인화가 높지만 품질 기준, 재실행 범위, 가격 설명이 복잡해진다.
- 따라서 중복 입력을 공유하면서도 독립된 결과물을 판매할 수 있는 7개 전문영역이 현재 구조에 가장 잘 맞는다.
- 현재 사람 서비스보다 낮은 가격으로 빠른 초안을 제공하고, 필요한 경우에만 사람 검증을 추가하는 구조가 AI 전환의 가치를 가장 명확하게 설명한다.
- 모델 원가는 판매가의 하한을 정하지만 고객이 지불하는 이유는 토큰이 아니라 조사시간 절감, 의사결정 위험 감소, 재사용 가능한 실행문서다. 따라서 가격은 원가가 아니라 원가 하한과 고객가치 상한을 함께 사용해야 한다.

### 검증 전 상품 가설

- 아래 가격은 기존 사람 서비스 가격을 기준점으로 만든 포지셔닝 가설이지 시장에서 확인된 지불의향이 아니다.
- 가격 확정 전 최소 10개 기업을 대상으로 결과물 유용성, 구매 의향, 재실행 의향을 확인해야 한다.
- 실제 원가에는 모델 사용료, 웹 검색, 보고서 저장, 재실행, 고객지원, 사람 검증 비용을 별도로 반영해야 한다.

## 3. 공통 에이전트 계약

모든 전문 에이전트는 같은 입력·출력 규칙을 따른다.

### 공통 입력

- 선택한 목표국가·도시·고객군·제품 또는 서비스
- 관련 준비도 질문의 선택값과 서술 답변
- 사용자가 제공한 내부 사실과 파일
- 다른 에이전트가 확인한 공통 기업정보와 근거
- 조사 기준일, 허용 언어, 통화, 계획기한

### 결제 후 작업 흐름

1. **업무 범위 확인:** 결제가 완료되면 구매한 에이전트가 만들 산출물, 목표국가, 계획기한, 사용 목적을 먼저 보여준다.
2. **필수정보 기술:** 사용자는 준비도 답변을 불러온 뒤 제품·고객·가격·현재 증거·제약·가용자원을 서술하고 관련 파일을 첨부한다. 이미 저장된 사실은 다시 묻지 않는다.
3. **입력 감사:** 에이전트는 답변을 `확인됨`, `불명확`, `누락`, `상충`으로 분류하고 결과를 크게 바꾸는 정보만 질문한다.
4. **최대 2회 추가질문:** 한 번에 가장 중요한 질문만 묶어 묻는다. 사용자가 충분히 답하면 즉시 조사로 넘어가며, 반복 질문으로 작업을 막지 않는다.
5. **모름 처리와 유사사례 추론:** 사용자가 `모름`을 선택하면 목표국가·산업·고객·가격대·유통방식이 가까운 공개 사례를 찾아 범위와 가정을 만든다. 사례가 부족하면 더 넓은 산업 벤치마크를 사용하되 신뢰도를 낮춘다.
6. **가정 확인 후 실행:** 에이전트는 핵심 가정, 적용한 유사사례, 제외한 정보와 민감도를 먼저 보여주고 사용자가 수정할 기회를 준 뒤 보고서와 실행계획을 생성한다.

### `모름` 응답 처리 규칙

- `모름`은 작업 중단 사유가 아니다. 에이전트가 공개자료·유사사례·범위 추정으로 빈칸을 보완한다.
- 유사사례는 국가, 산업, 고객, 가격대, 판매채널 중 일치한 조건과 다른 조건을 함께 표시한다.
- 추론값은 사용자 사실로 저장하지 않고 `유사사례 가정`으로 저장한다. 이후 실제 정보가 들어오면 해당 가정과 영향받은 계산·계획만 다시 산출한다.
- 단일 사례를 일반화하지 않는다. 가능하면 독립된 사례 또는 자료 2개 이상으로 삼각검증하고 low/base/high 범위를 제시한다.
- 규제 효력, 계약 해석, 실제 구매의향, 파트너 의향처럼 공개사례로 대체할 수 없는 항목은 추론하지 않고 `사람 검증 필요`로 남긴다.
- 1회 구매에는 추가질문 2회와 사용자 사실 정정에 따른 결과 재생성 1회를 포함한다. 목표국가·제품·핵심 고객이 바뀌면 새 범위로 본다.

### 공통 출력

- `확인된 사실`: 사용자 입력 또는 추적 가능한 출처로 확인된 내용
- `추정`: 공개자료와 명시된 가정으로 계산하거나 추론한 내용
- `미확인`: 출처·현장·내부자료가 부족한 내용
- `사람 검증 필요`: 법률·세무·인허가·계약 효력 또는 실제 관계 확인이 필요한 내용
- 산출물, 근거 URL·발행처·발행일·확인일, 신뢰도, 가정, 반대 근거, 다음 행동
- 성공 기준, 중단 기준, 책임자, 기한

### 금지 사항

- 실제로 수행하지 않은 인터뷰·구매·파트너 접촉을 완료했다고 표현하지 않는다.
- 비공개 연락처나 개인정보를 추론하거나 수집하지 않는다.
- 법률·세무·규제·계약 판단을 확정적 자문으로 표현하지 않는다.
- 단일 출처나 오래된 자료를 최신 시장 사실로 일반화하지 않는다.
- 근거가 부족한 숫자나 파트너 이름을 목표 개수를 맞추기 위해 생성하지 않는다.

## 4. 총괄 오케스트레이터

### 역할

1. 55개 답변을 Critical → 현재 Gate → 낮은 점수 → 사용자의 목표 순서로 정렬한다.
2. 질문별 주 담당 에이전트와 필요한 보조 에이전트를 선택한다.
3. 기업·제품·국가·고객 정의를 공통 컨텍스트로 만들어 중복 질문과 중복 검색을 줄인다.
4. 전문 에이전트 결과의 숫자, 국가, 기준일, 가정이 서로 충돌하는지 검사한다.
5. 사용자가 구매할 최소 충분 패키지와 사람 검증이 필요한 항목을 분리한다.
6. 최종적으로 경영진 요약, 핵심 위험, 산출물 링크, 30·60·90일 우선순위를 하나의 보고서로 통합한다.

### 완료 기준

- 적용된 55개 질문과 제외 이유를 추적할 수 있다.
- 같은 사실이 서로 다른 값으로 보고되면 하나를 임의 선택하지 않고 충돌로 표시한다.
- Critical 문항의 미충족이 일반 점수나 낮은 위험 액션으로 가려지지 않는다.
- 사용자는 각 권고가 어느 답변과 어느 근거에서 나온 것인지 확인할 수 있다.

## 5. 7개 전문 AI 에이전트

### A1. 시장정보·시장규모 에이전트

- **목적:** 목표국가와 초기 고객군을 비교하고 실제 접근 가능한 시장 범위를 추정한다.
- **주 입력:** 목표시장 항목 5문항, 제품·고객 정의, 가격·구매빈도·접근 가능한 고객 수.
- **조사:** 후보국 비교, ICP 밀도, 시장동향, 직접·인접·대체 경쟁사, TAM·SAM·SOM·교두보 시장 삼각검증.
- **산출물:** 후보국 비교표, ICP 정의·계정 산정 논리, 시장규모 low/base/high, 경쟁구도, 출처 원장, 증거 공백.
- **완료 기준:** 숫자별 산식·기준연도·통화·출처·가정이 있고 TAM ≥ SAM ≥ SOM 관계가 유지된다.
- **권장 단건 가격:** **149,000~299,000원 — 검증 전 상품 가설**.

### A2. 고객검증·실증시험 에이전트

- **목적:** 관심 표현을 실제 사용·지불·재구매 증거로 바꾸는 가장 작은 검증을 설계한다.
- **주 입력:** 본국 PMF 4문항, 시장 실증시험 5문항, 기존 고객·이탈·파일럿 기록.
- **조사·분석:** 구매 역할, 선택·거절 이유, 반대 증거, 현지 환경 조건, 메시지·데모·가격 검증 설계.
- **산출물:** 고객증거 감사표, 인터뷰 가이드, 참가자 기준, 유료 PoC·첫 주문 실험, KPI·성공·중단 기준, 결과 기록 양식.
- **완료 기준:** 실험이 검증할 가설, 표본, 기간, 고객 행동지표, 실패 판정이 구체적이다.
- **한계:** AI는 인터뷰·구매·파일럿을 실제 수행하거나 그 결과를 생성하지 않는다.
- **권장 단건 가격:** **79,000~199,000원 — 검증 전 상품 가설**.

### A3. 현지화·Local BMC 에이전트

- **목적:** 기존 사업모델에서 유지할 것, 반드시 바꿀 것, 실험할 것을 현지 BMC로 재구성한다.
- **주 입력:** 거래관행·본사 가정 차이, 현지 가격표시·결제, 사용자 여정 장애 질문.
- **조사·분석:** 고객세그먼트, 가치제안, 채널, 고객관계, 수익원, 핵심자원·활동·파트너, 비용구조와 LPA 6축.
- **산출물:** BMLC, 현지 BMC 9블록, LPA 6축, 유지·필수변경·제한실험 판단, 변경 백로그, 비용·기간·책임자.
- **완료 기준:** 모든 변경이 현지 근거 또는 검증과제에 연결되고 단순 번역을 현지화 완료로 취급하지 않는다.
- **권장 단건 가격:** **149,000~299,000원 — 검증 전 상품 가설**.

### A4. 규제·시장진입 요건 에이전트

- **목적:** 목표국의 제품분류와 판매 전 선결조건을 공식출처 중심으로 조사한다.
- **주 입력:** 제품분류, 인허가·인증, 적용 제외 근거 질문과 제품·산업·고객·유통 구조.
- **조사:** 규제기관 원문, 등록·인증·표시·품질·개인정보·보안·세금·수입자·책임주체 요건.
- **산출물:** 제품분류 가설, 공식출처 표, 필수·조건부·비적용 요건, 준비 순서, 예상 지연 위험, 재확인일.
- **완료 기준:** 공식출처와 확인일이 없는 요건을 확정하지 않고 상충하는 해석을 별도로 표시한다.
- **한계:** 제품분류·법률·세무·인허가·계약 효력의 최종 판단은 `사람 검증 필요`다.
- **권장 단건 가격:** **149,000~299,000원 — 검증 전 상품 가설**.

### A5. 현지 생태계·네트워크 에이전트

- **목적:** 국가 평균이 아니라 목표도시·산업 클러스터에서 필요한 고객·채널·전문가·공급자를 구조화한다.
- **주 입력:** 인프라 공급자, 본사-현지 가교, 파트너 확보·경제성·인터뷰·성과·의존도 질문.
- **조사:** 사용자, 구매자, 유통·조달, 규제실무, 협회, 액셀러레이터, 3PL·결제·클라우드·서비스 파트너.
- **산출물:** 도시·클러스터 생태계 지도, 역할별 후보 목록, 출처·최근 활동, 적합도·위험 점수, 접촉 질문, 실사 체크리스트, 대체경로.

- **한계:** 공개정보는 파트너의 실제 의향, 수행능력, 연락 가능성 또는 관계 형성을 보장하지 않는다.

### A6. TCE·재무·자원 에이전트

- **산출물:** TCE 모델, 현금 버팀기간, 최소 실행범위, 시나리오 손익, 예산 집행표, 용량 병목과 고객·채널 집중위험.
- **완료 기준:** 비용 범위·기간·통화·세금 포함 여부와 내부 입력·외부 추정을 구분한다.

- 총괄 오케스트레이터 비용은 각 상품 가격에 포함한다.

- 고객 표시가격에는 부가세 포함 여부를 명시하고, 내부 손익은 부가세를 제외한 공급가액으로 계산한다.

### GPT-5.6 Sol 원가식

2026-08-14 기준 공식 단가를 사용한다. 단가가 바뀌면 문서의 판매가를 즉시 바꾸는 대신 최근 30일 실제 원가율을 다시 계산한다.

```text
Sol 모델원가(USD)
= 비캐시 입력토큰/1,000,000 × 5
+ 캐시 입력토큰/1,000,000 × 0.5
+ 출력토큰/1,000,000 × 30

총 변동원가(KRW)
= Sol 모델원가 × 결제환율
+ 웹검색·파일검색·도구 호출료
+ 보고서 저장·전송비
+ 결제수수료
+ 고객지원 배부액
+ 재실행 충당액

원가 기준 최저 공급가
= 총 변동원가 ÷ (1 - 목표 공헌이익률 80%)
```

- 토큰은 한 번의 응답이 아니라 해당 주문의 모든 Sol 호출을 합산한다.
- 표준 단건의 초기 사용량 가정은 비캐시 입력 20만 토큰, 출력 4만 토큰으로 모델 원가 약 US$2.20이다. 심층조사는 입력 50만, 출력 8만 토큰으로 약 US$4.90이다. 이는 **운영 검증 전 원가 가설**이다.
- 결제환율은 실제 카드 청구환율을 사용하고 환율 변동 충당 10%를 내부 원가에 더한다.
- 캐시, 공통 기업정보, 조사 출처 재사용으로 절감한 비용은 중복 과금이 아니라 패키지 할인과 마진 안정에 사용한다.

### 고객가치 기준 가격식

판매가는 다음 두 기준 중 큰 값을 사용하되 고객 인터뷰에서 확인된 지불의향을 넘지 않는다.

1. **원가 하한:** 위 원가 기준 최저 공급가.
2. **가치 하한:** 같은 결과물을 사람이 만드는 비용의 10~30%, 또는 절감시간 × 고객 내부 시간단가의 20~40%.

가격을 높일 수 있는 근거는 더 많은 토큰이 아니라 다음 결과물이어야 한다.

- 다수 출처를 연결한 재현 가능한 조사 원장
- 의사결정에 바로 쓰는 비교표·계산·가정·민감도
- 책임자·기한·KPI·중단기준이 있는 실행계획
- 후속 에이전트가 재사용할 수 있는 구조화된 기업·시장 컨텍스트

- 주문별 실제 토큰·도구·재실행·지원비를 기록하고 월별로 에이전트별 원가율을 계산한다.

- 고객이 결과물을 의사결정이나 후속 실행에 사용하지 못하면 가격을 높이지 않는다. 결과물 활용률, 완료율, 재구매율, 환불률을 가격 검증 지표로 사용한다.
