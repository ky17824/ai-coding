# 콘텐츠 운영 기준

NotebookLM은 원문을 읽고 인용 위치를 확인하는 편집 공간으로만 사용한다.
플랫폼은 승인된 구조화 데이터만 읽으며 NotebookLM과 자동 동기화하지 않는다.

## 게시 절차

1. `data/content-coverage.csv`에서 `partial`인 칸만 조사한다.
2. 공식 기관·법령·표준 원문을 우선하고, 실무 블로그는 공식 자료가 없는 비용·기간 추정에만 사용한다.
3. NotebookLM 답변을 `data/notebooklm-export-template.csv` 형식으로 내보낸다.
4. 편집자가 원문과 인용 위치를 직접 확인하고 `review_status=approved`로 바꾼다.
5. 날짜가 있는 공고는 `expires_at`을 반드시 입력한다. 만료된 항목은 추천에서 제외한다.

## 월간 점검

- 지원사업 공고, 마감일, 신청 자격
- 법령·보안 표준의 개정 여부
- 비용·기간처럼 사업자 자료에 의존한 참고 추정치
- 링크 오류와 발행기관 변경

`TIPA` 표기는 `NIPA`로 정정했다. SOC 2 비용과 정부지원 금액은 공식
견적이나 공고가 아니면 사용자 화면에 “참고 추정치”로 표시한다.
