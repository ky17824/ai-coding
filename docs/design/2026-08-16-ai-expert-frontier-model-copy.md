# AI 전문가 서비스 모델 표기 원칙

## 결정

- 서비스 목록의 제목은 `준비도의 격차를 AI 전문가와 함께 줄여보세요`로 표시한다.
- 고객 화면에서는 특정 모델명을 노출하지 않고 한국어 `프론티어 모델`, 영어 `frontier model`로 통일한다.
- 적용 범위는 서비스 목록, 서비스 상세 안내, 유료 AI 전문가 작업 화면과 완료 보고서 헤더다.

## 운영 원칙

- 후속 프론티어 모델 교체가 고객 약속이나 화면 문구 변경으로 이어지지 않게 한다.
- 내부 API 모델 ID, 라우팅, 원가 계산, 사용량·감사 기록에는 실제 모델 식별자를 유지한다.
- 모델 성능 등급이 바뀌면 고객 화면 표기와 실제 라우팅의 일치 여부를 함께 검토한다.

## 검증 기준

- 공개 AI 전문가 여정에 `GPT-5.6 Sol` 또는 대소문자 변형이 노출되지 않는다.
- 한국어 화면에는 `프론티어 모델`, 영어 화면에는 `frontier model`이 표시된다.
- 내부 실행 모델과 비용 추적 로직은 변경하지 않는다.
