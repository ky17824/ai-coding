# 시장·경쟁 사전조사 한도 도달 후 다음 선택

## 목표

무료 시장·경쟁 사전조사 3회를 모두 사용한 사용자가 막힌 느낌 없이 마지막 조사 결과를 계속 활용하고, 더 깊은 조사가 필요할 때만 유료 AI 전문가 서비스를 검토하도록 한다.

## 사용자 흐름

1. 세 번째 조사가 완료되거나 기존 사용자가 한도에 도달한 상태로 화면을 열면 서버가 한도 상태를 전달한다. 이전 화면에서 추가 요청이 발생해 `research_limit`을 받는 경우도 일반 오류와 분리한다.
2. 재시도 버튼 대신 중립적인 다음 선택 카드를 표시한다.
3. 선택 1을 기본 행동으로 제공한다.
   - `마지막 시장보고서 보기 ↗`
   - 저장된 종합 시장보고서를 새 탭에서 연다.
4. 저장된 조사 결과가 있을 때만 선택 2를 함께 제공한다.
   - 기존 `ai-market-intelligence` 상품의 제목·설명·산출물·가격을 사용한다.
   - `AI 시장조사 전문가 알아보기 →`로 상품 상세에 이동한다.
5. 저장된 결과를 찾지 못하면 유료 상품을 권하지 않고 새로고침 또는 운영 문의를 안내한다.

## 화면 문구

- 제목: `무료 시장·경쟁 사전조사 3회를 모두 사용했습니다.`
- 설명: `마지막 조사 결과는 계속 확인할 수 있습니다. 현재 결과를 활용하거나, 더 깊은 분석이 필요하면 AI 시장조사 전문가를 이용해 보세요.`
- 기본 CTA: `마지막 시장보고서 보기 ↗`
- 보조 CTA: `AI 시장조사 전문가 알아보기 →`

영문 화면은 같은 의미와 위계를 유지한다.

## 디자인 원칙

- `DESIGN.md`의 cream canvas, white panel, deep green action, 12px card radius와 기존 버튼 규격을 재사용한다.
- 한도 도달은 실패가 아니므로 빨간 경고색과 `role="alert"`를 사용하지 않는다.
- 상태 카드는 `role="status"`, `aria-live="polite"`, 프로그램 포커스를 제공한다.
- 데스크톱에서는 두 선택을 나란히, 모바일에서는 한 열로 배치한다.
- 한도 도달 후에는 `다시 조사`와 `사전조사 다시 만들기` 버튼을 숨긴다.

## 데이터와 경계

- 새 DB 컬럼이나 마이그레이션을 추가하지 않는다.
- 기존 `market_research_count`와 업그레이드 상태를 서버에서 판정해 새로고침 후에도 한도 상태를 유지한다.
- 마지막 보고서는 기존 `/api/gtm-plans/{planId}/export?view=1`을 사용한다.
- AI 전문가 정보는 기존 `getAiAgentService("ai-market-intelligence")` 결과만 사용한다.
- 일반 네트워크·검증 오류에는 기존 재시도 동작을 유지한다.

## 검증 기준

- `research_limit`만 선택 카드로 전환된다.
- 선택 카드에는 재조사 버튼이 없다.
- 마지막 보고서 링크가 새 탭에서 열린다.
- 서비스 기능이 활성화되고 저장된 조사 결과가 있을 때만 전문가 카드가 보인다.
- 320px 화면에서 버튼과 카드가 잘리지 않는다.
