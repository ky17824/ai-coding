# 종합 시장보고서 Executive Research Brief 디자인

## 상태

- 승인됨: A안 `Executive Research Brief`
- 기준 샘플: 현재 `영웅입술` 미국 시장 사전조사 데이터
- 범위: 웹 보고서와 인쇄용 HTML의 정보 구조·시각 표현만 변경

## 목표

시장조사 결과를 경영진이 먼저 결론과 의사결정 포인트로 읽고, 필요한 경우 근거와 참고문헌까지 추적할 수 있는 전문 보고서로 정리한다. 긴 URL은 본문 카드와 표에서 제거해 레이아웃 깨짐을 막는다.

## 정보 구조

1. 보고서 도구 모음
2. 짙은 녹색 표지: 보고서 제목, 제품·서비스, 목표국가, 생성일
3. 핵심 메타데이터: 조사 범위, 출처 수, 도메인 수, 경쟁사 후보 수
4. 경영진 요약과 의사결정 제안
5. 준비도 적용 범위
6. 제품·서비스와 초기 고객 정의
7. TAM·SAM·SOM·교두보 시장 4개 요약 카드
8. 시장동향 요약
9. 경쟁구도
10. 상충 근거와 불확실성
11. 다음 검증 과제
12. 30·60·90일 계획(존재할 때만)
13. 가정과 한계
14. 참고문헌

## 출처와 인용

- 시장규모, 시장동향, 경쟁사, 상충 근거에서 사용한 출처를 한 번 수집해 최초 등장 순서로 번호를 부여한다.
- 같은 출처는 같은 번호를 재사용한다.
- 본문에는 원시 URL 대신 `[1]`, `[2]` 형식의 인용번호를 표시한다.
- 인용번호는 보고서 마지막의 `#ref-n` 참고문헌 항목으로 이동한다.
- 참고문헌에는 번호, 제목, 발행기관, 발행일 또는 확인일, 출처 유형을 표시한다.
- 유효한 HTTP(S) URL만 제목 링크로 제공한다. 기존 `safeHref` 검증을 재사용한다.
- URL이 없거나 안전하지 않으면 서지정보만 표시하고 링크는 만들지 않는다.
- 화면과 인쇄 본문에는 전체 URL을 노출하지 않는다.

## 시각 규칙

- 새 프레임워크나 의존성을 추가하지 않고 기존 보고서 HTML과 공통 디자인 토큰을 재사용한다.
- 표지는 짙은 녹색, 본문 캔버스는 cream, 콘텐츠는 흰색 표면을 사용한다.
- 글꼴은 `Pretendard Variable`, radius는 12px·16px, 간격은 4·8·16·24·32·48px 체계를 따른다.
- 시장규모 카드는 네 개의 동일한 위계를 사용하고, 숫자·상태·산식·핵심 한계 순으로 읽히게 한다.
- 시장동향과 경쟁구도는 긴 원문 카드 나열 대신 핵심 주장, 사업 시사점, 인용번호를 구조화해 표시한다.

## 반응형·인쇄·접근성

- 320px 화면에서 한 열로 전환하고 가로 스크롤이 생기지 않게 한다.
- 메타데이터는 데스크톱 4열, 태블릿 2열, 모바일 1열로 배치한다.
- 넓은 표는 모바일에서 라벨이 있는 카드형 행으로 전환한다.
- 인쇄 시 도구 모음과 그림자를 제거하고 핵심 카드·표 행 내부의 페이지 분할을 피한다.
- `main`, `section`, 순차적 heading 구조를 유지하고 키보드 focus를 표시한다.

## 검증 기준

- 출처 번호는 최초 등장 순서로 결정되고 중복 출처는 한 번호만 사용한다.
- 참고문헌 이외의 본문에는 원시 URL이 나타나지 않는다.
- 모든 참고문헌 링크는 HTTP(S) 안전성 검증을 통과한다.
- 현재 보고서의 40개 고유 출처를 레이아웃 파손 없이 표시한다.
- 320px 화면에 가로 overflow가 없다.
- 인쇄 스타일에서 도구 모음과 그림자가 제거된다.
- 기존 조직 권한, 다국어 표시, HTML escaping과 XSS 방어는 그대로 유지된다.
