# AI 시장·경쟁 사전조사 Top-Down 시장규모 설계

## 목표

AI 시장·경쟁 사전조사의 TAM·SAM·SOM·교두보 시장을 공개 외부자료에 근거한 **Top-Down 방식**으로만 산정한다. 창업자의 예상 가격, 고객 수, 판매역량이나 ICP 인구를 곱하는 Bottom-up 계산은 사전조사 결과에 사용하지 않는다.

## 계산 계약

- **TAM:** 동일한 시장 정의로 정규화한 최근 3년 이내 독립 공개 시장매출 자료 2개를 교차검증해 low/base/high를 산정한다.
- **SAM:** TAM에 최신 근거가 있는 지역, 고객 적합성, 채널, 규제 필터를 적용한다.
- **SOM:** SAM에 공개자료 기반 3~5년 획득 가능 점유율 1~5%를 적용한다. 창업자 판매역량으로 상한을 씌우지 않는다.
- **교두보 시장:** SAM에 최초 고객군, 지역 또는 채널의 집중 비중을 적용한다. 고객 수×고객당 매출 계산을 사용하지 않는다.
- 숫자마다 통화, 기준연도, low/base/high, 산식, 가정, 출처를 유지하며 TAM ≥ SAM ≥ SOM 계층을 서버에서 검증한다.
- 근거가 부족하면 숫자를 만들지 않고 `insufficient_evidence`와 구체적인 근거 공백을 표시한다.

## 사용자 표시

- 네 시장규모 카드에 계산 방법을 **Top-Down**으로 표시한다.
- 한국어 보조 설명은 `공개자료 기반 하향식 추정`, 영어는 `Top-Down estimate from public evidence`로 표시한다.
- 보고서에도 같은 방법명을 사용해 화면과 다운로드 결과가 일치하게 한다.

## 호환성과 재조사

- 기존 `market-sizing-v2` 결과는 열람 가능하게 보존한다.
- 새 조사는 `market-sizing-v3-top-down`으로 생성하고, v2 캐시는 새 방식 결과로 간주하지 않는다.
- 조사 횟수를 모두 사용한 기존 v2 사용자에게는 v3 전환을 위한 원자적 1회 재조사 기회를 제공한다.
- 새 v3 생성 성공 전까지 기존 확정 보고서는 보존한다.

## 구현 범위

- 시장규모 구조화 출력 스키마와 서버 계산기
- 시장규모 조사 프롬프트
- 조사 캐시·방법론 버전·1회 업그레이드 판정
- 어시스턴트 UI와 종합 시장보고서의 방법 표시
- v2 정규화 호환, v3 계산·계층·출처·업그레이드 회귀 테스트

## 제외 범위

- AI 전문가 유료 서비스의 별도 시장규모 보고서 계약
- 기존 v2 저장 데이터의 일괄 재계산
- DB 컬럼 추가 또는 새 외부 의존성
