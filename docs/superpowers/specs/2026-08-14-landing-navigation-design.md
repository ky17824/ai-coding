# 랜딩페이지 내비게이션 단순화 설계

## 목표

랜딩페이지의 주요 메뉴를 첫 진입에 필요한 두 경로로 단순화해 사용자가 준비도 진단과 AI 전문가 서비스에 바로 집중하도록 한다.

## 동작

- 한글 랜딩페이지(`/`)와 영문 랜딩페이지(`/en`)의 데스크톱·모바일 주요 메뉴에는 두 항목만 표시한다.
- 메뉴 순서는 `준비도 진단 → AI 전문가 서비스`로 한다.
- 영문 문구는 `Assessment → AI Expert Services`로 표시한다.
- 랜딩페이지에서는 `대시보드`와 `GTM 여정`을 표시하지 않는다.
- 언어 선택, 로그인·로그아웃, 운영, 마이페이지 등 계정 영역은 유지한다.
- 랜딩페이지 이외 화면의 기존 주요 메뉴와 `AI GTM 어시스턴트` 조건은 변경하지 않는다.

## 구현 범위

- 기존 `SiteHeader`에 선택적인 랜딩 메뉴 모드를 추가한다.
- `Landing` 컴포넌트만 랜딩 메뉴 모드를 전달한다.
- `AI 전문가 서비스` 전용 한·영문 헤더 문구를 추가하며 기존 `전문가 서비스` 문구는 다른 화면에서 유지한다.
- 새 라우트, 의존성, 클라이언트 상태는 추가하지 않는다.

## 검증

- 랜딩 모드의 데스크톱·모바일 메뉴가 두 항목과 올바른 링크만 포함하는지 테스트한다.
- 일반 헤더와 대시보드 전용 AI GTM 어시스턴트 메뉴가 그대로 유지되는지 회귀 테스트한다.
- 랜딩 컴포넌트가 랜딩 메뉴 모드를 전달하는지 테스트한다.
- 전체 테스트, 타입검사, 프로덕션 빌드를 통과한다.
- 운영 랜딩페이지에서 데스크톱·모바일 메뉴를 확인한다.
