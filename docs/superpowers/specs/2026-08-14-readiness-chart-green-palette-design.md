# 준비도 차트 녹색 팔레트 디자인

## 목표

대시보드 Q1–Q18 막대그래프의 노랑·주황·갈색 계열을 제거하고 Borderless의 기존 녹색 브랜드 체계 안에서 상태 위계가 즉시 구분되게 한다.

## 디자인

- 차트 전용 토큰은 기존 `--green-dark`, `--green-uplift`, `--green`, `--mint`에서 파생한다.
- `필수 선결 조건`은 딥그린 사선, `90일 검증`은 회녹색 세로선, `보완 필요`는 세이지 단색과 점선, `통과`는 민트, `강점`은 브랜드 그린으로 표시한다.
- 색에만 의존하지 않도록 현재의 사선·세로선·점선 패턴과 상태 문구를 유지한다.
- 같은 상태색을 막대, 범례, 선택 상세의 왼쪽 경계와 상태 칩에 일관되게 적용한다.
- 막대 높이, 점수 산식, 키보드 조작, 모바일 가로 스크롤과 선택 동작은 변경하지 않는다.

## 검증

- CSS 회귀 테스트로 기존 노랑 계열 색상 제거와 새 상태 토큰 사용을 고정한다.
- 기존 차트 컴포넌트 테스트, 전체 테스트, 타입 검사와 프로덕션 빌드를 통과한다.
