# AI GTM 선택 입력·Sol 사전조사 설계

## 원칙

- 극초기 창업기업이 알기 어려운 예상 가격, 구매 빈도, 초기 접근 고객 수, 3년 판매·공급 범위, 현재 검증 근거, 제약은 선택 입력이다.
- 여섯 항목이 비어 있어도 사전조사를 중단하거나 부정적 증거로 해석하지 않는다.
- 사용자가 입력한 사실, 정제된 업로드 자료, 준비도 진단, 승인된 내부 자료와 공개 웹 근거만 사용한다.
- 누락된 시장규모 값은 공개자료를 교차검증해 범위로 추정하고, 창업자 입력인지 외부 자료 기반 가정인지 구분한다.
- 시장동향, 경쟁구도, 시장규모, 최종 종합은 모두 `gpt-5.6-sol`로 생성한다. 원문 정제는 검색 없는 기존 경량 모델을 유지한다.

## UI

여섯 필드의 한·영문 라벨과 placeholder에 각각 `선택`/`Optional`을 표시하고, 모르면 비워 두어도 AI가 공개자료로 추정한다는 안내를 필드 안에 둔다.

## 완료 기준

- 빈 선택 필드로도 조사 요청이 유효하다.
- 네 조사 생성 단계가 모두 Sol을 사용한다.
- 기존 개인정보 제거, 출처 허용목록, 서버 재계산, 조사 횟수 제한은 변경하지 않는다.
