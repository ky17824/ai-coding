# AI GTM 어시스턴트 내비게이션 설계

## 목표

상단 내비게이션에서 AI GTM 어시스턴트를 바로 열 수 있게 하고, 메뉴 순서를 `준비도 진단 → AI GTM 어시스턴트 → GTM 여정`으로 명확히 한다.

## 동작

- 데스크톱과 모바일 메뉴에 `AI GTM 어시스턴트`를 추가한다.
- 영문 메뉴에는 `AI GTM Assistant`를 표시한다.
- 메뉴 링크는 `/assistant`를 사용한다.
- `/assistant`는 로그인 사용자의 조직에서 가장 최근 진단을 조회해 `/assistant/{assessmentId}`로 이동한다.
- 진단이 없으면 `/assessment`로 이동한다.
- 로그인하지 않은 사용자는 기존 인증 규칙에 따라 로그인 화면으로 이동한 뒤 `/assistant`로 돌아온다.

## 구현 범위

- 기존 `SiteHeader`의 공통 메뉴 배열과 i18n 헤더 문구를 확장한다.
- 동적 진단 ID를 해결하는 서버 라우트 `app/assistant/page.tsx`를 추가한다.
- 기존 `/assistant/[assessmentId]` 화면과 데이터 계약은 변경하지 않는다.
- 새 의존성이나 별도 클라이언트 상태는 추가하지 않는다.

## 검증

- 메뉴 순서와 한·영문 문구를 컴포넌트 테스트로 고정한다.
- `/assistant`의 로그인, 진단 있음, 진단 없음 리디렉션을 테스트한다.
- 전체 테스트, 타입검사, 프로덕션 빌드를 통과한다.
- 운영 대시보드에서 메뉴 클릭이 최신 AI GTM 어시스턴트 화면으로 연결되는지 확인한다.
