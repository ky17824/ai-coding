# AI GTM 어시스턴트 내비게이션 설계

## 목표

사용자 대시보드의 데스크톱 상단 내비게이션에서 AI GTM 어시스턴트를 바로 열 수 있게 하고, 메뉴 순서를 `준비도 진단 → AI GTM 어시스턴트 → GTM 여정`으로 명확히 한다.

## 동작

- 진단이 있는 사용자 대시보드의 데스크톱 메뉴에만 `AI GTM 어시스턴트`를 추가한다.
- 영문 메뉴에는 `AI GTM Assistant`를 표시한다.
- 메뉴 링크는 현재 대시보드가 표시하는 최신 진단의 `/assistant/{assessmentId}`를 사용한다.
- 모바일 메뉴와 대시보드 이외의 페이지에는 이 메뉴를 표시하지 않는다.
- 진단이 없는 대시보드에는 이 메뉴를 표시하지 않는다.

## 구현 범위

- 기존 `SiteHeader`에 선택적인 데스크톱 전용 어시스턴트 링크 속성과 i18n 헤더 문구를 추가한다.
- 대시보드가 최신 진단 ID로 어시스턴트 링크를 전달한다.
- 기존 `/assistant/[assessmentId]` 화면과 데이터 계약은 변경하지 않는다.
- 새 라우트, 의존성, 별도 클라이언트 상태는 추가하지 않는다.

## 검증

- 데스크톱 메뉴 순서, 한·영문 문구, 모바일 메뉴 제외를 컴포넌트 테스트로 고정한다.
- 대시보드가 최신 진단의 어시스턴트 링크를 전달하는지 테스트한다.
- 전체 테스트, 타입검사, 프로덕션 빌드를 통과한다.
- 운영 대시보드에서 메뉴 클릭이 최신 AI GTM 어시스턴트 화면으로 연결되는지 확인한다.
