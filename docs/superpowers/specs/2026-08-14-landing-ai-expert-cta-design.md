# 랜딩 AI 전문가 CTA 설계

## 목표

랜딩페이지 네 번째 이용방법 카드를 현재 AI 전문가 서비스에 맞는 문구와 진입점으로 바꾼다.

## 설계

- 기존 `step-card` 시각 규칙을 그대로 사용한다.
- 제목은 `AI 전문가가 진출 과제를 해결합니다`로 변경한다.
- 설명은 시장조사·현지화·규제·재무·실행계획과 준비도 답변 기반 결과물을 명시한다.
- 카드 전체를 로케일별 `/services` 경로로 연결한다.
- 영문 페이지도 같은 의미와 연결 구조를 적용한다.

## 검증

- 한글·영문 문구와 서비스 링크를 컴포넌트 테스트로 확인한다.
- 전체 타입 검사와 프로덕션 빌드를 통과한다.
